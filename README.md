# Jin Portfolio

This repository now uses a Vue 3 + Vite application at the repository root, with legacy CSS carried over from the archived React version for closer visual parity.

## Commands

- `npm run dev`
- `npm run build`
- `npm run preview`

## Layout

- Root: active Vue portfolio app
- `archived/`: legacy React application preserved for reference, including its previous dependencies
- `.work-plans/`: migration planning and progress records
